# Codebase state

nbdev v3 static docs/report project estimating memory-bandwidth-bound LLM decode TPS and comparing to published/local llama.cpp measurements. Config lives in `pyproject.toml`; report notebooks/scripts live in `nbs/`; README is generated from `nbs/index.ipynb`. nbdev is used as static site/README builder, not as library generator. `quaternion-lab/` is a separate statically built SvelteKit educational app with no integration into the nbdev site.
